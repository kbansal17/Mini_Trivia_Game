# 🎉 Mini Trivia Game

A colorful and animated trivia web app built with **Flask (Python)** and **vanilla HTML/CSS/JS**. It shows a series of fun questions with immediate feedback and a final score display.


## 🚀 Features

- ✨ 5 Hardcoded Trivia Questions (served via Flask)
- 🎨 Beautiful gradient background with smooth animations
- ✅ Instant feedback for correct/wrong answers
- 🧠 Final score display after all questions
- ⚡ Loads super fast (no external libraries!)

---

## 📂 Tech Stack

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Python + Flask

---

## 🖥️ Running Locally

1. **Clone the repo**  
   ```bash
   git clone https://github.com/<your-username>/mini-trivia-game.git
   cd mini-trivia-game
````

2. **Create a virtual environment (optional but recommended)**

   ```bash
   python -m venv venv
   venv\Scripts\activate  # On Windows
   ```

3. **Install dependencies**

   ```bash
   pip install flask
   ```

4. **Run the app**

   ```bash
   python app.py
   ```

5. Open your browser and go to `http://127.0.0.1:5000`
